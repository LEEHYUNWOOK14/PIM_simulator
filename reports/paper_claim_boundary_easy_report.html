논문 결과,
어디까지 믿고 말할 수 있나요?

실험 결과마다 “컴퓨터에서 동작을 확인한 것인지”, “실제로 칩 배치를 해 본 것인지”, “아직 계산이나 가정에 불과한지”를 구분했습니다. 논문이 확보한 증거보다 더 강하게 말하지 않도록 자동 검사도 추가했습니다.

STOB PIM2 · 작성일 2026-08-13 · 기준: Physical Feasibility Gate

한눈에 보는 결론

현재 상태: 4단계까지 통과, 마지막 1단계는 대기 회로의 기본 동작, 합성, 통합 합성, 부품 배치는 확인했습니다. 그러나 부품 사이의 모든 배선을 실제로 연결할 수 있는지는 아직 증거가 완성되지 않았습니다.
따라서 이렇게 이해하면 됩니다.

“설계가 컴퓨터상에서 동작했고 칩 위에 부품을 놓을 수 있었다”는 말은 가능합니다. 하지만 “배선까지 문제없이 가능하다” 또는 “제조 가능한 칩이다”라고 말할 단계는 아닙니다.

칩을 만드는 5단계 검사

집을 짓는 과정에 비유하면 이해하기 쉽습니다. 설계도를 시험하고, 자재 목록으로 바꾸고, 방을 배치한 뒤, 마지막으로 전선과 배관이 모두 지나갈 수 있는지 확인하는 흐름입니다.

PF-0 PASS

동작 시험

컴퓨터 시뮬레이션에서 회로의 기본 행동과 데이터 흐름을 확인했습니다.

PF-1 PASS

부품 변환

어댑터 설계를 실제 반도체 셀 조합으로 바꿀 수 있음을 확인했습니다.

PF-2 PASS

통합 설계 변환

PCU와 어댑터를 합친 큰 설계도 셀 조합으로 변환했습니다.

PF-3 PASS

부품 배치

변환된 부품들을 정해진 칩 영역 안에 겹치지 않게 배치했습니다.

PF-4 PENDING

전체 배선

배선 완료 결과와 혼잡도 자료가 아직 충분하지 않습니다.

PASS는 해당 단계의 제한된 검사를 통과했다는 뜻이며, 완성 칩이나 양산 가능성을 뜻하지 않습니다.

결과에 붙이는 여섯 가지 꼬리표

서로 다른 종류의 증거를 하나의 “실측 결과”처럼 섞지 않기 위해 각 결과에 아래 꼬리표를 자동으로 붙입니다.

rtl_simulated

회로 동작 시뮬레이션

칩 설계 언어로 작성한 회로가 시험 조건에서 의도대로 움직였다는 뜻입니다.

synthesized

합성됨

회로 설명을 실제 반도체 기본 부품들의 조합으로 변환했다는 뜻입니다.

placed

배치됨

합성된 부품을 칩의 제한된 공간에 실제 좌표로 놓아 보았다는 뜻입니다. 배선 완료와는 다릅니다.

modeled

모델 계산값

정해진 수식과 조건으로 계산한 결과입니다. 실제 칩에서 측정한 값은 아닙니다.

estimated

공학적 추정값

공개 자료와 가정을 이용한 예상값입니다. 제조사 공개값이나 견적이 아닙니다.

illustrative

설명용 그림·값

구조를 쉽게 보여 주기 위한 예시입니다. 실제 제조 치수나 배선도를 의미하지 않습니다.

논문에서 가능한 말과 금지되는 말

✓ 현재 증거로 말할 수 있음

  • 어댑터는 보고된 RTL 기능 시험을 통과했다.
  • 통합 설계는 공개 Sky130 환경에서 합성·기술 매핑되었다.
  • 현재 넷리스트는 최종 배치 위반 0건으로 합법적인 거친 배치에 도달했다.
  • 성능·전력·열 값은 명시한 조건 아래의 모델 계산 결과다.

✕ 아직 말하면 안 됨

  • “이 설계는 routing feasible하다.”
  • “혼잡 없이 전체 배선이 가능하다.”
  • “40 ns 목표 주파수에서 타이밍이 닫혔다.”
  • “제조·양산 가능한 설계” 또는 “실리콘에서 검증되었다.”

왜 막았나요? PF-4가 아직 PENDING이고, 전체 배선 완료 파일·혼잡도 보고서·배선 초과량 0이라는 증거가 모두 갖춰지지 않았기 때문입니다. 자동 검사기는 PF-4가 통과하기 전까지 routing feasible, routable 같은 긍정 표현을 오류로 처리합니다.

현재 evidence matrix

각 주장과 그 주장을 뒷받침하는 증거 종류를 연결한 표입니다. BLOCKED는 자료가 전혀 없다는 뜻이 아니라, 그 자료만으로 해당 주장을 확정할 수 없다는 뜻입니다.

자동 보호 장치가 하는 일

1

증거 파일 확인

각 결과가 가리키는 파일이 실제로 존재하는지 확인하고, 파일 크기와 SHA-256 지문을 기록해 나중에 바뀐 자료를 구분합니다.

2

여섯 등급 자동 부여

결과가 RTL 시험, 합성, 배치, 모델, 추정, 설명용 자료 중 어디에 해당하는지 일관된 규칙으로 분류합니다.

3

물리 검사 단계와 연결

PF-0부터 PF-4까지의 현재 상태를 읽고, 필요한 단계가 통과하지 않았다면 해당 주장을 자동으로 BLOCKED 처리합니다.

4

과장 문구 탐지

PF-4가 PENDING인 동안 배선 가능성을 확정하는 문구가 보고서에 들어오면 검사를 실패시킵니다.

앞으로 PF-4를 통과하려면

전체 배선 작업이 끝났다는 표시만으로는 충분하지 않습니다. 현재 설계와 같은 버전에서 생성된 결과인지 확인하고, 배선 가이드와 혼잡도 보고서가 존재하며, 배선 용량 초과가 0이고, 예외 처리된 고팬아웃 신호가 허용 목록에 포함되는지까지 검증해야 합니다.

중요: PF-4를 통과하더라도 그것은 가벼운 전역 배선 가능성 검사입니다. 상세 배선, 클록 트리, 실제 배선 지연 추출, 전압 강하, 전자 이동, DRC/LVS, 제조 및 실리콘 검증은 별도의 더 강한 단계입니다.
