1. 목적과 완료 조건

목적: Bank-side 구조에 Logic-die PCU hierarchy를 추가했을 때 발생하는 면적·timing·power 비용과, bank/logic 계층 처리로 얻는 reduction·routing 성능을 측정한다. B1은 B2의 normalization 전용 하드웨어 효과를 분리하기 위한 ablation baseline이기도 하다.
  • Bank → Logic-die operand 전달과 result return이 stall/backpressure 조건에서 PASS한다.
  • Scheduler, coalescer, epoch, shared buffer, reduction 및 router가 의도대로 포함된다.
  • Sky130 mapped area와 10 ns target의 STA가 확보된다.
  • 동일 floorplan 조건의 physical 지표가 확보된다.
  • 동일 work 단위의 Logic hierarchy activity-based power가 확보된다.

5. B1 전용 기능 자극

  • bank_result_to_logic_i=1로 Bank result를 Logic operand path에 전달
  • Logic command coalescing, epoch begin/fill done/execution done/release 순서 검증
  • shared weight write/read/context commit 및 backpressure 검증
  • Logic PCU result의 tag/channel 보존과 scheduler issue/retirement 검증
  • cross-channel reduction 계약 및 duplicate/context error 검증
  • result router의 Bank/Host destination 분기와 ready/valid stall 검증
  • Normalization sideband가 OFF 상태에서 idle이며 hierarchy 동작을 오염하지 않는지 확인

6. B0와 독립 실행할 때 지켜야 할 비교 규칙

B1은 독립 합성·배치·배선이 가능하다. 그러나 B0와 최종 비교할 때는 같은 source freeze에서 B0도 함께 재현해야 한다. 특히 B1은 큰 shared buffer와 control logic이 포함되므로, memory inference/macro 처리 정책이 B0와 다르면 cell delta가 왜곡된다.
