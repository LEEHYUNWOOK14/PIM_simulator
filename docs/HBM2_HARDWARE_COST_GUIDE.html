HBM2 PIM 설계를 실제로 만들 때 필요한 실리콘 면적, 3차원 패키지, 제조수율, 전력·성능과 열·냉각부담을 한 흐름으로 비교하는 방법을 회로·소자 관점의 언어로 설명합니다.

왜 필요한가파이프라인5개 비용축근거와 출처현재 결과RTL 완료 후GitHub에서 찾기실행법

1. 왜 온도 이외의 비용을 보는가?

HBM은 DRAM 다이를 수직으로 쌓고 TSV와 micro-bump로 연결합니다. 온도가 안전해도 다이가 커지거나 접합 수가 늘고, 수율이 낮거나 전력 대비 성능이 나쁘면 좋은 하드웨어라고 할 수 없습니다.

mm²
면적

칩 하나의 평면 면적과 적층 전체에서 제조해야 하는 누적 실리콘 양입니다.

TSV
패키지

수직 배선, 범프, 접합면, interposer가 요구하는 제조 자원입니다.

Y
수율

여러 die와 접합이 모두 정상인 완성 stack을 얻을 확률입니다.

J/op
전력·성능

유용한 연산이나 데이터 전송 하나를 위해 쓴 에너지입니다.

K/W
열·냉각

발생 전력이 만드는 온도상승, 열저항, 열 여유와 필요한 냉각부담입니다.

중요: 이 분석은 제조사의 실제 원가표가 아닙니다. 공개되지 않은 wafer 가격·결함밀도·접합수율은 범위로만 다루며, 결과는 설계 대안의 상대 비교용입니다.

각 분석기는 JSON 결과만 주고받습니다. 따라서 RTL이 수정 중일 때는 synthetic 입력으로 실행하고, RTL이 끝나면 합성·배치·activity 결과만 교체할 수 있습니다.

숫자를 합치는 순서: 먼저 단위가 있는 물리량을 계산하고 → 기준 8Hi를 1.0으로 정규화하고 → 비용지수와 성능을 분리해 비교하고 → 마지막에 열·용량 제약과 불확실성을 적용합니다.

3. 다섯 개의 비용축

① Area

logic die, DRAM die, PIM 추가 logic, PHY 예약영역, TSV keep-out zone을 분리합니다.

누적 실리콘 = logic + Ndie × DRAM

현재 절대 면적은 illustrative입니다. RTL 완료 후 Yosys/OpenROAD 면적으로 교체합니다.

② Package

interposer 면적, micro-bump 수, TSV 수, 접합면 수, 배선 요구량을 사용합니다.

package index = Σ wᵢ × 정규화 자원ᵢ

가중치는 가격표가 아니라 비교 정책이며 모두 설정파일에 노출됩니다.

③ Yield

die 결함과 3D 접합 실패를 분리합니다. 결함 clustering을 고려하는 negative-binomial 식을 사용합니다.

Ydie=(1+D₀A/α)−α
Ystack=Ylogic·ΠYDRAM·Ybond·YTSV·Yassembly

④ Power / Performance

이론 대역폭, 실제 사용률, 전력, energy/bit, PIM speedup을 계산합니다.

1024 bit ÷ 8 × 2.4 Gb/s = 307.2 GB/s

307 GB/s는 Samsung 공개 HBM2 사양과 일치하는 검산점입니다.

⑤ Thermal

3D 온도장에서 최고온도, 온도상승, 등가 열저항, 열 여유와 냉각부담을 계산합니다.

thermal burden = ΔT / (Tlimit−Tambient)

비용지수에 포함되지만 실제 heatsink 가격이나 제조사 signoff 온도는 아닙니다.

4. 근거를 어떻게 구분했나?

분류뜻예사용 방법
manufacturer_public제조사가 공개한 사실1024-bit, 2.4 Gbps, 307 GB/s사양 검산에 직접 사용
peer_reviewed논문이 제공한 모델 구조negative-binomial yield, 3D yield 분해식의 근거로 사용
open_source_model재현 가능한 공개 도구CACTI memory area/power model향후 교차검증 adapter
project_config이 프로젝트에서 정한 값8GB workload 요구량조건으로 명시
estimated / illustrative공개 근거가 없는 탐색값결함밀도, bond yield, PIM 면적단일 사실이 아닌 범위 분석

CACTI나 McPAT 논문이 존재한다고 해서 현재 설정한 4.8 mm² PIM 면적을 보증하지는 않습니다. 그래서 식의 출처와 숫자의 출처를 분리했고, 공개되지 않은 숫자는 모두 project_cost_assumption으로 표시했습니다.

핵심 공개 근거: Samsung Aquabolt HBM2, Samsung Flashbolt HBM2E, SK hynix TSV/HBM2 설명, CACTI 7, McPAT, 3D stacked-IC yield 연구, negative-binomial yield 연구, Berkeley Roofline 모델.

6. RTL 수정이 끝나면 무엇이 달라지는가?

실제값으로 승격 가능

  • 표준셀/PIM/버퍼 면적
  • 배치 utilization과 혼잡도
  • VCD/SAIF 기반 동적 전력
  • 처리량·지연·유효 대역폭
  • 블록별 전력의 3D 위치 매핑
  • 시나리오별 온도장·hotspot·열저항

여전히 추정으로 남음

  • 제조사 웨이퍼 가격
  • 실제 defect density
  • bond/TSV/assembly yield
  • 고객별 HBM 가격
  • 제조사 내부 PHY/TSV GDS

즉 RTL 완료 후 면적·전력·성능은 훨씬 현실적으로 바뀌지만, 제조수율과 가격은 vendor/NDA 또는 측정자료가 없으면 계속 범위 모델입니다.
