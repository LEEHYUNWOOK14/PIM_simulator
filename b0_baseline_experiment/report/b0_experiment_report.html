1. 최종 결론

B0는 Logic-die PCU와 normalization engine을 제외한 bank-side PCU 기준선으로 기능 검증, 합성, 배치배선, GDS 생성, activity 기반 전력 추정까지 전 과정을 완료했다. 따라서 이후 B1과 동일 technology/constraint/scale 아래에서 area·timing·power overhead를 비교할 수 있는 재현 가능한 기준점이 확보됐다.

중요: 10 ns setup timing을 만족하지 못했고 detailed-route DRC 16,720건 및 antenna violation이 남아 있다. 그러므로 본 결과는 architecture feasibility/PPA 비교용이며 tapeout 또는 signoff-clean 결과로 표현하면 안 된다.

6. B1과 비교할 때 반드시 지킬 조건

  1. 동일 RTL revision, Sky130 liberty/LEF, 10 ns clock, 0.2 ns uncertainty를 사용한다.
  2. B1도 동일 1-channel/2-bank/DW32 최소 scale로 먼저 측정한다.
  3. Area는 mapped-to-mapped, final-to-final처럼 같은 정의끼리 비교한다.
  4. Power overhead는 B0와 같은 두-ADD workload를 우선 사용한다. Normalization workload 전력은 B0에서 동등 연산이 없으므로 별도 절대값으로 표기한다.
  5. Normalization latency, cross-bank traffic, memory I/O reduction은 architecture/model 결과로 분리한다. B0의 normalization latency를 0으로 두고 speedup을 계산하면 안 된다.
  6. 양쪽 중 하나라도 DRC/timing 미달이면 “signoff PPA”가 아니라 “동일-flow implementation estimate”로 표현한다.
보고서용 핵심 문장: Logic-die 기능이 없는 B0 bank-side baseline을 동일한 RTL-to-GDS flow로 구현한 결과, 기능 동작과 physical artifact 생성을 확인했다. 이 기준선은 B1의 추가 logic area/power 및 timing cost를 정량화하는 데 사용하되, 현 단계의 timing·DRC 위반 때문에 결과는 architecture-level implementation estimate로 한정한다.
