PIMSimulator

시뮬레이터 구조 안내서

이 문서는 프로젝트의 1번부터 4번까지, 즉 PIMKernel.cpp를 이해하기 위해 먼저 알아야 할 구조를 순서대로 정리한 가이드입니다. 화면에 보이는 UI 프로그램이 아니라, C++ 테스트와 시뮬레이터 내부 로직이 어떻게 연결되는지 이해하는 데 초점을 맞췄습니다.

src/MemorySystem.*, src/PIMRank.*

전체 그림

1. 테스트가 시작된다 GoogleTest가 `PIMKernelFixture.gemv`, `add`, `mul`, `relu` 같은 테스트를 실행합니다.
2. PIMKernel가 입력과 명령을 준비한다 데이터를 메모리에 올리고, CRF에 PIM 명령을 넣고, PIM 모드 전환을 처리합니다.
3. 명령어가 실제 시뮬레이션 이벤트로 바뀐다 `PIMCmdGen`와 `PIMCmd`가 만든 명령이 메모리 트랜잭션으로 변환됩니다.
4. 메모리 시스템이 사이클 단위로 실행한다 `MemorySystem`, `MemoryController`, `PIMRank`가 채널, 랭크, 뱅크 상태를 갱신합니다.

1. 테스트 진입점부터 보기

가장 먼저 볼 파일은 src/tests/KernelTestCases.cpp입니다. 여기에는 TEST_F(PIMKernelFixture, gemv) 같은 테스트가 있고, 각 테스트가 어떤 입력 크기로 커널을 실행하는지 확인할 수 있습니다.

  • gemv_tree, gemv, mul, add, relu가 핵심 기능 테스트입니다.
  • 이 파일은 “무엇을 시험하는가”를 보여주고, 실제 계산 구현은 PIMKernel.cpp로 넘어갑니다.
  • 즉, 이 프로젝트는 UI 버튼이 아니라 ./sim --gtest_filter=...로 돌리는 테스트 중심 구조입니다.

2. PIMKernel.cpp 읽기

이 파일이 핵심입니다. PIMKernel 클래스는 PIM 연산을 시뮬레이터에 “요청”하는 쪽이고, 실제로는 메모리 트랜잭션과 상태 전환을 조합해서 연산을 구성합니다.

  1. parkIn(), parkOut()로 PIM 모드 진입과 복귀를 준비합니다.
  2. programCrf()로 PIM 명령어들을 CRF에 씁니다.
  3. executeGemv(), executeEltwise()가 연산 흐름의 중심입니다.
  4. computeGemv(), computeAddOrMul(), computeRelu()가 실제 반복 동작을 만듭니다.
이 파일은 “버튼 누르는 UI”가 아니라, “시뮬레이터가 어떤 순서로 메모리 명령을 넣어야 하는지”를 적은 실행 스크립트에 가깝습니다.

3. PIMCmd.* 이해하기

src/PIMCmd.h와 src/PIMCmd.cpp는 PIM ISA를 담는 쪽입니다. 즉, ADD, MUL, MAC, MOV, FILL, JUMP, EXIT 같은 명령이 어떤 32-bit 값으로 표현되는지 다룹니다.

  • PIMCmdGen는 상황별 명령 묶음을 생성합니다.
  • PIMCmd는 그 명령을 인코딩하고 유효성도 체크합니다.
  • PIMKernel.cpp는 여기서 만든 명령을 받아 실행 순서에 맞게 적재합니다.

4. MemorySystem / PIMRank 보기

마지막으로 src/MemorySystem.*와 src/PIMRank.*를 보면, 명령이 실제 시뮬레이터 내부에서 어떻게 전달되고 처리되는지 보입니다.

  • MemorySystem은 전체 요청을 받고, 사이클을 굴리는 상위 시스템입니다.
  • MemoryController는 채널 단위 명령 큐와 스케줄링을 관리합니다.
  • PIMRank는 PIM 모드 전환, CRF 실행, PIM 블록 연결을 담당합니다.

따라서 PIMKernel.cpp를 읽을 때는 “내가 만든 요청이 어디로 흘러가서 어떤 상태가 바뀌는가”를 같이 보면 훨씬 빨리 이해됩니다.

추천 학습 순서

  1. src/tests/KernelTestCases.cpp로 테스트 종류를 익힌다.
  2. src/tests/PIMKernel.cpp로 실행 순서를 따라간다.
  3. src/PIMCmd.*로 명령어 구조를 이해한다.
  4. src/MemorySystem.*, src/PIMRank.*로 시뮬레이터 내부 흐름을 확인한다.
./sim --gtest_list_tests
./sim --gtest_filter=PIMKernelFixture.gemv
./sim --gtest_filter=PIMBenchFixture.gemv

한 줄 요약

PIMKernel.cpp는 UI가 아니라, 시뮬레이터 내부에서 PIM 연산을 실제로 “어떻게 돌릴지” 적어둔 핵심 실행 코드입니다. VSCode는 편집기이고, 실행은 터미널에서 `sim`을 돌리는 방식입니다.
